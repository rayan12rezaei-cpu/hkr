# هفت‌خان رستم

بازی دوبعدی مترویدونیا، موبایل‌محور و بدون وابستگی خارجی.

## اجرا
فایل `index.html` را در یک وب‌سرور محلی یا هاست استاتیک باز کنید. چون کد از ES Modules استفاده می‌کند، اجرای مستقیم با `file://` ممکن است در برخی مرورگرها محدود شود.

مثال محلی:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید.

## ساختار
- `index.html` رابط، منو، HUD و پنل‌ها
- `css/style.css` ظاهر و طراحی رابط
- `js/data.js` نقشه، هفت خان و نواحی
- `js/game.js` موتور بازی، کنترل لمسی، دشمنان، باس‌ها، نقشه، آهنگری، ذخیره و کات‌سین

## طراحی روایی
ترتیب هفت‌خان بر پایه روایت شناخته‌شده شاهنامه تنظیم شده: شیر، بیابان و تشنگی، اژدها، زن جادو، اولاد، ارژنگ دیو و دیو سپید. جزئیات محیط و مسیرها برای تبدیل روایت به ساختار مترویدونیا به‌صورت بازی‌سازی بازطراحی شده‌اند.

مرگ نهایی رستم نیز به‌صورت کات‌سین غیرگرافیکی با نیرنگ شغاد روایت شده است.

منبع مرجع متنی: شاهنامه فردوسی در گنجور، به‌ویژه «پادشاهی کی‌کاووس و رفتن او به مازندران» و «داستان رستم و شغاد».
